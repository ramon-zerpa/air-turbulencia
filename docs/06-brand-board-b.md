## Fotografía y aplicación

Se muestran dos imágenes del sitio actual para ilustrar detalle del trabajo y equipo en contexto. No se certifica que sean fotografías propias ni trabajos de la empresa. Se indica esta limitación en el board.

Botones principales azul petróleo con texto blanco; secundarios delineados. Radio discreto de 4 px, iconos de línea Lucide y reglas finas. El board no define todavía una composición de homepage.
